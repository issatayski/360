# Заливка на shared-хостинг (cPanel) — Фаза 0

Каркас: PHP + MySQL, статический фронт, вьюер Pannellum. Node/Next не нужны.

## 1. Создай БД MySQL
cPanel → **MySQL Databases**: создай базу, пользователя, привяжи пользователя к базе
со всеми правами. Запиши имя базы, юзера, пароль, хост (обычно `localhost`).

## 2. Залей файлы
Содержимое папки `public_html/` этого репозитория → в `public_html/` (или иной
webroot) на хостинге, по FTP или через File Manager. Структура должна остаться:
`index.php`, `lib/`, `api/`, `assets/`, `uploads/`, `view.php`, и т.д.

## 3. Пропиши доступ к БД
Открой `lib/config.php`, заполни:
```php
const DB_DRIVER = 'mysql';
const DB_HOST = 'localhost';
const DB_NAME = 'твоя_база';
const DB_USER = 'твой_юзер';
const DB_PASS = 'твой_пароль';
```
И при желании смени `SEED_EMAIL` / `SEED_PASSWORD` (логин первого агента).

## 4. Инициализируй
Открой в браузере `https://твой-домен/setup.php` — он создаст таблицы и заведёт
агента. Затем:
- проверь, что `uploads/` доступна на запись (права `0755`/`0775`);
- **удали `setup.php`** с хостинга.

## 5. Проверь
- `https://твой-домен/` → форма входа → войди под seed-агентом.
- Создай тур → загрузи 360-фото (equirect 2:1) **или** нажми «Снять режимом A».
- Опубликуй тур → открой публичную ссылку `view.php?slug=...` (работает без входа).
- Скопируй `<iframe>` из карточки тура и вставь на любую страницу.

## Требования и заметки
- **HTTPS обязателен** для съёмки режима A (камера + гироскоп доступны только по https).
- PHP 8.0+ (используются `str_starts_with`, типы). Расширения: `pdo_mysql`, `gd`
  (для `getimagesize`; есть почти везде).
- Лимит загрузки панорамы — 25 МБ (`MAX_UPLOAD_BYTES` в config). Если фото крупнее,
  подними на хостинге `upload_max_filesize` и `post_max_size` (php.ini / cPanel → MultiPHP INI).
- **Без .htaccess.** Этот хостинг отвечает 500 на директивы в .htaccess (урезан
  `AllowOverride`), поэтому файлов `.htaccess` в проекте нет. Безопасность держится
  так:
  - `lib/config.php` — это `.php`: сервер его **исполняет**, а не отдаёт исходник,
    поэтому креды БД не видны из браузера (при работающем PHP). Хочешь надёжнее —
    вынеси `config.php` выше webroot и поправь пути `require` в `lib/db.php` и
    `lib/helpers.php`.
  - `uploads/` — загруженные файлы **всегда** сохраняются под нашим именем с
    расширением `.jpg/.png` (см. `store_panorama`), плюс проверяется, что это
    реальное изображение. Загрузить исполняемый `.php` нельзя.
  - `schema.sql` и этот README не содержат секретов; если хочется их спрятать —
    просто удали с хостинга после установки.
