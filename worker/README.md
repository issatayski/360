# Воркер склейки 360 («облако» платформы)

Это наш аналог облака Matterport: принимает кадры со смартфона + гиро-позы,
**выравнивает их по признакам изображения** (ORB + bundle adjustment над
вращениями с якорем к гиро-позам) и отдаёт резкую equirect-панораму. Именно
выравнивание по признакам убирает мыло/двоение, которого не победить склейкой
на телефоне по одному гироскопу.

Клиент ничего не покупает и снимает любым телефоном — вычисления берёт на себя
этот один сервер платформы.

## Почему отдельный сервер, а не shared-хостинг
PHP на shared-хостинге не умеет тяжёлую компьютерную графику (нет OpenCV, лимиты
времени/памяти). Поэтому воркер живёт там, где есть вычисления. Это **фиксированная
статья расходов платформы**, а не клиента.

## Где запустить (дёшево/бесплатно)
Любой хост с Docker или Python:
- **Render.com** — есть бесплатный веб-сервис (спит без нагрузки), из коробки по Dockerfile.
- **Fly.io / Google Cloud Run** — есть бесплатные лимиты, разворачивают контейнер.
- **Hugging Face Spaces (Docker)** — бесплатно, удобно для проб.
- **VPS ~$4–5/мес** (Hetzner/Timeweb/…): `docker build && docker run`.

Локально:
```bash
cd worker
pip install -r requirements.txt
python app.py            # слушает :8080
# или прод-режим:
gunicorn -b 0.0.0.0:8080 -w 1 -t 180 app:app
```

## Переменные окружения
- `WORKER_TOKEN` — общий секрет; PHP шлёт его в заголовке `X-Worker-Token`. Задай
  одинаковым тут и в `lib/config.php` сайта.
- `MAX_WIDTH` — потолок ширины панорамы (по умолчанию 4096).
- `PORT` — порт (по умолчанию 8080).

## Контракт API
`POST /stitch` (multipart/form-data):
- `manifest` — JSON: `{ "hfov":50, "width":4096, "frames":[ {"name":"f00","yaw":..,"pitch":..,"roll":..}, ... ] }`
- по файлу-картинке на каждый `frames[].name` (поле `f00` = картинка f00).
- заголовок `X-Worker-Token: <секрет>`.

Ответ: `image/jpeg` (equirect 2:1). Заголовки `X-Coverage` (доля покрытия) и
`X-Refined` (1 — позы уточнены по признакам, 0 — остались гиро).

`GET /health` → `{"ok":true}`.

## Проверка
```bash
curl -sf http://localhost:8080/health
```
После деплоя пропиши URL воркера в `lib/config.php` сайта (`WORKER_URL`) и секрет
(`WORKER_TOKEN`).

## Замечание про качество
Выравнивание по признакам работает, когда в комнате есть текстура (обои, мебель,
картины). На голых однотонных стенах совпадений мало — тогда кадр остаётся на
гиро-позе (не хуже прежнего). Алгоритм будем докручивать на реальных съёмках —
плумбинг для этого готов.
